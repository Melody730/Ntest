第 2 站 · N卡设置

检查 NVIDIA 的录制设置 🎮

别人的声音走“系统音频”，你的声音走“麦克风”——这一站专门查麦克风这一路。

为什么能录到别人、却录不到自己？

N 卡录制会同时抓两路声音：一路是系统声音（游戏、语音软件里别人的说话声），另一路是麦克风（你自己的说话声）。两路互不影响，所以系统声音正常、麦克风没开或选错设备时，录像里就只剩别人的声音。

你平时用的是哪个 NVIDIA 录屏工具？

怎么打开：按 Alt + Z 呼出 NVIDIA 叠加层 → 点齿轮 ⚙️ → 找到音频，看看里面有没有麦克风开关和设备选择。
新版叫 NVIDIA App，旧版叫 GeForce Experience，位置都在这个齿轮里。

第 3 站 · 系统权限

看看 Windows 有没有放行 🪟

系统声音和麦克风在 Windows 里是两套权限，这一步查的是麦克风。

路径：按 Win 键 → 设置 → 隐私和安全性 → 麦克风；
另外，右键任务栏右下角的小喇叭 🔊 → 声音设置 → 输入，可以看默认设备和音量条。
